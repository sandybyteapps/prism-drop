# Prism Drop website

Static source for a Sandybyte-branded Prism Drop home, support and privacy site. No build step, scripts or analytics. The mark and generated `sandybyte.css` are copied from the SandybyteBrandKit in `00_sandybyte`; retain their original colours and proportions.

Sandybyte app websites use a separate public GitHub Pages repository for each app. The Prism Drop site is intended for `sandybyteapps/prism-drop`:

- `https://sandybyteapps.github.io/prism-drop/`
- `https://sandybyteapps.github.io/prism-drop/support/`
- `https://sandybyteapps.github.io/prism-drop/privacy/`

To publish updates, copy this folder's contents into a clone of the Pages repository, commit and push to its publishing branch. Verify the public pages after changes. The privacy wording must be kept consistent with the app's actual AdMob/UMP configuration and App Privacy disclosures. The support address is `support@sandybyte.com`.
